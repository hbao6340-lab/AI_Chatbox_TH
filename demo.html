Chatbot Widget có thể nhúng vào bất kỳ website nào

Giới thiệu

Đây là một widget chatbot có thể nhúng vào bất kỳ website nào. Widget được thiết kế để hiển thị ở góc dưới bên phải của trang, có thể mở/đóng dễ dàng.

Widget sử dụng cùng backend và cơ sở tri thức với trang fullscreen, cung cấp thông tin về Phường Tân Hưng.

Tính năng

💬

Hội thoại

📱

Responsive

Dễ nhúng

Chèn vào website với 1 dòng code

Cách nhúng vào website

Thêm đoạn code sau vào cuối thẻ <body> của website bạn:

<!-- Chatbot Widget -->
<link rel="stylesheet" href="https://your-domain.com/widget.css">
<div id="chat-widget-container">
    <div class="chat-widget-header">
        <div class="header-info">
            <div class="header-avatar"><img src="avatar.png" alt="Avatar"></div>
            <div class="header-text">
                <h3 class="header-title">Trợ lý ảo</h3>
                <p class="header-subtitle">Hỗ trợ Tân Hưng</p>
            </div>
        </div>
    </div>
    <div id="chat-messages" class="chat-messages">
        <div class="welcome-message">
            <p>Xin chào! Tôi là trợ lý ảo. Bạn cần hỗ trợ gì?</p>
        </div>
    </div>
    <div class="chat-input-area">
        <input type="text" id="chat-input" placeholder="Nhập tin nhắn...">
        <button id="send-btn">Gửi</button>
    </div>
</div>
<button id="chat-widget-toggle">💬</button>
<script src="https://your-domain.com/widget.js"></script>

Cấu hình

Widget sẽ tự động phát hiện môi trường và sử dụng API phù hợp:

  • Localhost: http://localhost:8000
  • Production: https://ai-supporter-vn-backend.onrender.com

Bạn có thể tùy chỉnh API base bằng cách đặt biến window.CHATBOT_API_BASE trước khi load widget.
